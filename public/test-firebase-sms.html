Test: Signup → Real SMS verification

What this tests: When a new user signs up with a phone number, the system sends a real SMS to that phone with a 6-digit code. The user enters the code to verify and sign in. This page lets you test that flow – you will receive a real SMS on the number you enter.

How to run: Run php artisan serve, then open http://127.0.0.1:8000/test-firebase-sms.html in your browser. Why this page? Firebase only sends a real SMS if the request includes a reCAPTCHA token. That token can only be created in a browser (or in your app), not in Postman/curl – so to test real SMS you use this page.
