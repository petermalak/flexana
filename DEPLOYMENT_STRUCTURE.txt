│ │   ├── resources/                    ← Raw Assets & Views                 │

Create Symlink:
┌─────────────────────────────────────────────────────────────────────────────┐
│ $ cd /domains/admin-panel-flexana-egypt/                                    │
│ $ rm -rf public_html                                                        │
│ $ ln -s /domains/admin-panel-flexana-egypt/flexana/public public_html      │
│ $ ls -la public_html                                                        │
│   → public_html -> /domains/admin-panel-flexana-egypt/flexana/public       │
└─────────────────────────────────────────────────────────────────────────────┘

PUBLIC (Web Accessible via public_html):
┌─────────────────────────────────────────────────────────────────────────────┐
│ ✅ index.php              - Laravel entry point                             │
│ ✅ .htaccess              - URL rewriting rules                             │
│ ✅ css/                   - Compiled stylesheets                            │
│ ✅ js/                    - Compiled JavaScript                             │
│ ✅ images/                - Public images                                   │
│ ✅ fonts/                 - Web fonts                                       │
│ ✅ robots.txt             - SEO instructions                                │
│ ✅ favicon.ico            - Site icon                                       │
└─────────────────────────────────────────────────────────────────────────────┘

PRIVATE (MUST NOT be web accessible):
┌─────────────────────────────────────────────────────────────────────────────┐
│ 🔒 .env                   - SECRETS & PASSWORDS                             │
│ 🔒 vendor/                - PHP Dependencies (security risk)                │
│ 🔒 storage/               - Logs, cache, user uploads                       │
│ 🔒 app/                   - Application source code                         │
│ 🔒 config/                - Configuration files                             │
│ 🔒 database/              - Migrations & seeds                              │
│ 🔒 routes/                - Route definitions                               │
│ 🔒 bootstrap/cache/       - Application cache                               │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│  DEPLOYMENT WORKFLOW                                                         │
└─────────────────────────────────────────────────────────────────────────────┘

Step 1: Upload Application
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                              │
│  Local Machine                    →    Production Server                    │
│                                                                              │
│  Git Repository                        /domains/admin-panel-flexana-egypt/  │
│  or ZIP Archive                              └── flexana/                   │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘

Step 2: Install Dependencies
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                              │
│  composer install --no-dev    →    vendor/ directory created               │
│  npm ci                       →    node_modules/ created                   │
│  npm run build                →    public/css & public/js created          │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘

Step 3: Configure Environment
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                              │
│  .env.example                 →    .env (with production values)           │
│  php artisan key:generate     →    APP_KEY generated                       │
│  php artisan migrate          →    Database tables created                 │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘

Step 4: Link Public Folder
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                              │
│  public_html/                 →    Symlink to flexana/public/              │
│                                    OR Copy with modified index.php          │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘

Step 5: Optimize & Go Live
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                              │
│  php artisan optimize         →    Caches created                          │
│  chmod permissions            →    Storage writable                        │
│  Test in browser              →    Site live! 🚀                           │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘


┌─────────────────────────────────────────────────────────────────────────────┐
│  COMPARISON: Symlink vs Move Public                                         │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────┬──────────────────────┬──────────────────────────────┐
│ Feature             │ Symlink (Method 1)   │ Move Public (Method 2)       │
├─────────────────────┼──────────────────────┼──────────────────────────────┤
│ Server Requirements │ Needs symlink support│ Works anywhere               │
│ Security            │ ⭐⭐⭐⭐⭐ Excellent     │ ⭐⭐⭐⭐ Good                  │
│ Ease of Setup       │ ⭐⭐⭐⭐⭐ Very Easy     │ ⭐⭐⭐ Medium                  │
│ Maintenance         │ ⭐⭐⭐⭐⭐ Minimal       │ ⭐⭐⭐ Regular                 │
│ Updates             │ Just pull code       │ Copy assets after build      │
│ File Duplication    │ None                 │ Yes (public files)           │
│ Recommended For     │ VPS, Dedicated       │ Shared hosting               │
└─────────────────────┴──────────────────────┴──────────────────────────────┘


┌─────────────────────────────────────────────────────────────────────────────┐
│  QUICK COMMANDS REFERENCE                                                    │
└─────────────────────────────────────────────────────────────────────────────┘

Navigate to App:
$ cd /domains/admin-panel-flexana-egypt/flexana

Check Application:
$ php artisan about

View Routes:
$ php artisan route:list

Check Logs:
$ tail -f storage/logs/laravel.log

Clear Caches:
$ php artisan optimize:clear

Optimize App:
$ php artisan optimize

Run Migrations:
$ php artisan migrate --force

Create Admin:
$ php artisan make:filament-user

Verify Structure:
$ ls -la /domains/admin-panel-flexana-egypt/
$ ls -la /domains/admin-panel-flexana-egypt/public_html
